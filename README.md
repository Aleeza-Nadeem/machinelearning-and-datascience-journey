## 💳 Featured Portfolio Projects

### 1. Credit Card Fraud Detection
* **Objective:** Built an end-to-end binary classification model to detect fraudulent transactions within highly imbalanced financial datasets.
* **Key Highlights:**
  * Handled extreme class imbalance using strategic resampling and scaling techniques.
  * Evaluated models using Precision-Recall curves, ROC-AUC, and Confusion Matrices to minimize false negatives.
  * Implemented and compared classification algorithms including Logistic Regression and Decision Trees.
* **Dataset Note:** The raw training and testing CSV files can be downloaded directly from the [Kaggle Credit Card Fraud Detection Dataset](https://www.kaggle.com/datasets).
### 2. Iris Flower Classification
* **Objective:** Applied multi-class classification algorithms to categorize iris species based on sepal and petal measurements.
* **Key Highlights:**
  * Conducted Exploratory Data Analysis (EDA) to evaluate feature relationships and class separability.
  * Implemented Logistic Regression and Decision Tree models to compare accuracy and decision boundaries.

### 3. Random Forest Classification
* **Objective:** Implemented ensemble learning using Random Forest models to analyze feature importance and improve predictive performance.
* **Key Highlights:**
  * Evaluated bagging techniques and decision tree aggregation to prevent model overfitting.
  * Analyzed precision, recall, and overall model metrics against single decision tree baselines.

### 4. Linear & Polynomial Regression Analysis
* **Objective:** Developed baseline predictive regression models to analyze linear vs. non-linear relationships in data.
* **Key Highlights:**
  * Implemented feature scaling and degree selection for polynomial fitting.
  * Analyzed residual plots and loss optimization (MSE/RMSE) to identify underfitting vs. overfitting.
